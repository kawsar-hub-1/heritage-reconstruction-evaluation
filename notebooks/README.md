# Research notebooks

1. **01_bamiyan_scoring_toolkit.ipynb** — calibration, structured annotation, weighted scoring and export.
2. **02_advanced_image_evaluation.ipynb** — ROI-aware structural/perceptual metrics and uncertainty analysis.
3. **03_reliability_sensitivity_analysis.ipynb** — reliability, confidence intervals, sensitivity and leave-one-criterion-out checks.
4. **04_multicriteria_ranking.ipynb** — equal weighting, entropy-TOPSIS, Borda aggregation and ranking robustness.

The notebooks are cleaned public versions of the research workflow. Execution outputs are deliberately removed, and restricted source images and participant-level data are not distributed.
